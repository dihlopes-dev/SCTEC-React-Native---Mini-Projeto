## 🚀 Estrutura do Quadro

O quadro está organizado em colunas que refletem o ciclo de vida de desenvolvimento do software:

### 1. 📌 Backlog
Contém todas as ideias, requisitos do projeto e funcionalidades planejadas que ainda não foram iniciadas.
* Definição de requisitos do projeto (M1S6 - SCTEC).
* Levantamento de histórias de usuário e casos de uso.

### 2. ⏳ To Do (A Fazer)
Tarefas priorizadas e prontas para entrar em desenvolvimento no ciclo atual.
* Estruturação inicial do projeto Node.js.
* Definição da hierarquia de classes (POO).

### 3. 🚧 In Progress (Em Andamento)
Atividades que estão sendo desenvolvidas ativamente no momento.
* Criação do menu interativo via CLI (`prompt-sync`).
* Implementação do algoritmo de recomendação e compatibilidade.

### 4. 🔍 In Review / Test (Em Revisão / Teste)
Funcionalidades desenvolvidas que passam por testes de validação, tratamento de erros e revisão de código.
* Validação de campos obrigatórios no cadastro de perfil (`do...while` e `.trim()`).
* Testes de integração de conceitos avançados (*Closures*, *Async/Await*, *Callbacks*).

### 5. ✅ Done (Concluído)
Tarefas 100% finalizadas, testadas e aprovadas para entrega.
* Modelagem de classes (`Conteudo`, `Filmes`, `Series`).
* Implementação de carregamento assíncrono do catálogo (`async/await`).
* Notificação de conclusão via *Callback*.
* Criação da documentação (`README.md`, `KANBAN.md`, `package.json`).
